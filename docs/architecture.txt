Microservices:
  User Service: Registration, Login, JWT, Users
  Game Service: Game, PGN, Moves
  Analytics Service: Stockfish + Gemini game analysis
  Statistics Service: Statistics, Aggregation, Chess portrait (Gemini)

Technical stack:
  Programming Language: Java 21
  Framework: Spring Boot
  Build Tool: Gradle
  Database: PostgreSQL
  ORM: Hibernate
  Asynchronous Messaging: Apache Kafka
  External Integrations: Stockfish, Gemini API
