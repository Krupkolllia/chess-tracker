1. User registers or logins. (User Service)
2. User loads game in PGN. (Game Service)
3. User gets game analysis for every move with comments on critical moments (Analysis Service)
4. User gets a question whether add this game to his own games (there is the chance,
   he just wanted to analyze not his own game. So this should be
   in his games section and won't be counted to statistics). (Game Service)
4.1. If answer to previous question is "No" - user sees nothing new. Maybe some functionality for
    this case will be created in the future. (Game Service)
4.2. If answer is "Yes" - user sees the game with analysis (if exists)
     in section with his games. (Game Service)
4.2.1. User sees the small message with "Game added. Statistics will be updated shortly". (Game Service)
5. User navigates to Statistics section and sees all of his statistics, exactly (will be changing):
    - Your chess portrait (generated by Gemini)
    - Amount of wins/draws/loses with white/black/both pieces
    - Winrate with white/black/both pieces.
    - Average accuracy with white/black/both pieces.
    - Amount of "brilliant" moves.
    - Average/maximum/minimum moves count in one game with white/black/both pieces
    - Average centipawns loss with white/black/both pieces
    - Average blunders/mistakes/inaccuracies per game with white/black/both pieces
    - Average move of first mistake
    - Average move of first blunder
    - Most played openings
    - Accuracy for every opening played at least 3 (not decided yet) times
    - Amount of wins/draws/loses with white/black/both pieces for every opening.
    (Statistics Service)
